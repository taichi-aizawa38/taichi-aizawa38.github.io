Shikumi Uploader

プライバシーポリシーと説明 ／ Privacy Policy and description　—　最終更新 2026年11月26日

Shikumi Uploader は、YouTube チャンネル「お金と世界のしくみ研究所」の運営者が、自分で作った動画を自分のチャンネルにアップロードし、公開日時を予約するためだけに使う個人用のデスクトップ用スクリプトです。運営者本人以外の利用者はいません。
Shikumi Uploader is a private desktop script used only by the owner of the YouTube channel “お金と世界のしくみ研究所” to upload the owner’s own original videos to the owner’s own channel and schedule their publication. It has no other users.

1. このツールがすること

  • 運営者のパソコンにある動画ファイルと予約表を読み、YouTube Data API で動画をアップロードし、タイトル・説明・カテゴリ・サムネイル・公開日時を設定します（videos.insert、thumbnails.set）。
  • 運営者が予約表で動画を差し替えたときだけ、運営者自身がアップロードしたまだ公開前の動画を削除します（videos.delete）。
  • 公開後、運営者自身のコメントを書き込むことがあります（commentThreads.insert）。

It reads video files and a schedule on the owner’s computer and uses the YouTube Data API to upload videos and set their title, description, category, thumbnail and scheduled publish time. It deletes only the owner’s own not-yet-published videos when the owner replaces them in the schedule, and may post the owner’s own comment after publication.

2. 公開されている動画の調べもの

運営者が自分の動画の企画のために、YouTube で一般に公開されている動画・チャンネルの情報（タイトル、公開日、再生回数、チャンネル名など）を検索・取得します（search.list、videos.list、channels.list、playlistItems.list）。取得した情報は運営者のパソコンの中でだけ使い、公開・第三者への提供はしません。YouTube API サービスのデベロッパー ポリシーに従い、保存した公開データは30日以内に削除または更新します。

For planning the owner's own videos, the tool searches and retrieves information about publicly available YouTube videos and channels (title, publish date, view count, channel name, etc.) via search.list, videos.list, channels.list and playlistItems.list. This data is used only on the owner's computer, is never published or shared with third parties, and stored public data is deleted or refreshed within 30 days in accordance with the YouTube API Services Developer Policies.

3. 扱うデータ

  • 使うのは、運営者が Google のログイン（OAuth）で許可した、運営者自身の YouTube チャンネルへの操作の権限だけです（youtube.upload、youtube.force-ssl、自分のチャンネルの分析の数字を読む yt-analytics.readonly）。
  • ほかの人のアカウントや、非公開の情報にアクセスすることはありません。
  • 許可の鍵（OAuth トークン）と、どの動画を上げたかの記録は、運営者のパソコンの中にだけ保存され、ほかのサーバーや第三者に送られることはありません。
  • 広告、解析ツール、Cookie は使いません。

The tool only uses the permissions the owner granted via Google OAuth for the owner’s own channel (youtube.upload, youtube.force-ssl, and yt-analytics.readonly to read the owner’s own channel analytics). It does not access any other person's account or any non-public data. The OAuth token and the upload log are stored only on the owner’s computer and are never sent to any other server or third party. No ads, analytics or cookies are used.

4. 第三者への提供

このツールが扱うデータを第三者に提供・販売することはありません。データの送り先は、運営者の操作を実行するための YouTube（Google）だけです。

No data is shared with or sold to third parties. Data is sent only to YouTube (Google) to carry out the owner’s own actions.

5. 許可の取り消しと削除

許可は、Google アカウントの「サードパーティ製のアプリとサービス」（https://myaccount.google.com/permissions）からいつでも取り消せます。取り消すと、ツールはチャンネルを操作できなくなります。パソコンに保存した鍵と記録は、運営者がいつでも削除できます。

Access can be revoked at any time from Google Account → Third-party apps & services (https://myaccount.google.com/permissions). The locally stored token and log can be deleted by the owner at any time.

6. YouTube と Google の規約

このツールは YouTube API サービスを使っています。利用にあたっては YouTube 利用規約 と Google プライバシー ポリシー が適用されます。

This tool uses YouTube API Services. By using it you are bound by the YouTube Terms of Service and the Google Privacy Policy.
